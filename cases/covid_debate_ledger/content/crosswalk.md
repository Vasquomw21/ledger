# Crosswalk — the index

Maps each concept note ↔ its sibling review ↔ primary source ↔ source section. The writing
assistant reads this first when answering a query (then drills into the named loci), and updates
it on every ingest. Keeping it current is what lets the knowledge base scale without
embedding-based search.

This case's source-of-truth is the claim ledgers themselves (one per voice); concept notes and
reviews are added only if a synthesis deliverable is written on top of them.
