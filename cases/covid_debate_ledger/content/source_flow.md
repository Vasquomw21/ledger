# Source Flow

This case follows the public Rootclaim-style debate trail rather than a systematic database search.
The flow records the route each included source took into the corpus; it does not claim the search is
complete.

## Overview

**Review-question:** Which linked public records explain the Rootclaim-style COVID-origins debate verdict and its competing probabilistic interpretations?
**Inclusion-criteria:** Sources must be part of the linked debate/adjudication trail, represent a declared debate position or method critique, and have stamped verified-claim ledgers.
**Exclusion-criteria:** Sources outside the debate trail, inaccessible materials, and commentary that does not add a distinct voice or claim are excluded or listed as gaps.
**Update-procedure:** Add a search row and included/excluded/unavailable entry for any newly ingested debate source; update semantic health when a new voice changes the verdict or method map.
