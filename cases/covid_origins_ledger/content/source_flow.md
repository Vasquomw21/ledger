# Source Flow

This case was assembled as a targeted, adversarial corpus rather than a systematic review. The
flow records the route each included source took into the corpus; it does not claim the search is
complete.

## Overview

**Review-question:** Which primary sources best test the furin-cleavage-site and market-origin claims in the COVID-origins case?
**Inclusion-criteria:** Sources must address either FCS engineering/naturalness or origin locus, represent a declared position in `source_register.md`, and have stamped verified-claim ledgers.
**Exclusion-criteria:** Sources outside those two sub-questions, sources lacking accessible quotable text, and sources that would duplicate an already captured claim without changing the graph are excluded or listed as gaps.
**Update-procedure:** Add a new search row and included/excluded/unavailable entry when a source is added or rejected; update semantic health if the new source changes a position or gap.
