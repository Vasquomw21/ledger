What it does

Ledger builds a knowledge base from sources, and keeps every quote in it true to its source.

  1. 01

    Collect

    Pick a source. Ledger downloads it, or you add the file.

  2. 02

    Quote

    Copy out the claims that matter, quoting the source.

  3. 03

    Check

    Ledger confirms each quote is in the source, word for word.

  4. 04

    Connect

    Link the claims: this one supports that one, this one argues against it, this later one overtakes it.

  5. 05

    Review

    People and AIs add judgements on top: which claims carry the argument, which sources lean on the same data, where a quote is being stretched. Judgements never change the quotes.

  6. 06

    Write

    Use the checked quotes as evidence in your writing. In the files Ledger checks, a citation to an unchecked quote fails.

Each new source adds quotes and links, and each new quote is checked.

An AI can do all of this, and the checks still hold. People can do it by hand, only slower. Either way, the human’s main job is review.

Why it exists

AI reads fast, but it can misquote a paper or credit it with a claim it never made.

Ledger catches that at the quote, before it spreads.

How it works

Quotes are fingerprinted

A checked quote is stamped with a fingerprint of itself and of its source. If the quote is edited later, Ledger catches it.

Judgements are sealed

An edited judgement shows.

Checks run in three places

When you commit, on GitHub, and, in Claude Code, as you write.

Guarantees

What it guarantees, and what it doesn’t.

Guaranteed

Each quote you cite is in its source.

This applies to the files you choose to check (gated, authored prose).

Not guaranteed

  • That the source is right. Sources can be wrong. Add the later work and link it to the claim it corrects.
  • That you have the right sources. Ledger can’t find what you missed. It records why each source is in, and the gaps you know of.
  • That quotes are used fairly. Anyone can challenge how a quote is used. Ledger does not rule on it.
  • That your conclusion follows. Ledger shows what it rests on, and which sources share data.
  • A full re-check online. Source files stay on your machine, so GitHub checks the fingerprints only.

Get started

Needs Python 3.10 or newer. Nothing to install.

Run a case

$ git clone https://github.com/Vasquomw21/ledger.git
$ cd ledger
$ make demo DIR=cases/covid_origins_ledger

Start your own

  1. Copy the kit and run git init.
  2. Turn on the commit check: git config core.hooksPath .githooks.
  3. Run ledger init.
  4. Add sources and write.
