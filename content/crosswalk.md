# Crosswalk — the index

Maps each concept note ↔ its sibling review ↔ primary source ↔ paper section. The writing
assistant reads this first when answering a query (then drills into the named pages), and
updates it on every ingest. Keeping it current is what lets the knowledge base scale without
embedding-based search.
